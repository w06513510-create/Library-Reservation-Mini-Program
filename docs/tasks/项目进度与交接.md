**三大亮点**：① 可视化平面图选座/寻书　② 信用分体系 + SnailJob 定时任务　③ 数据可视化大屏。
**范围红线**：违规只走「信用分 + 黑名单」，**不涉及任何金钱/支付**。

## 五、关键约定与踩坑（务必先读，避免返工）

- **SQL 应用顺序有依赖**：`schema → menu_library → menu_desk → snailjob_library → role_perm → menu_library_ext → role_perm_ext → deruoyi → seed_support → seed_seats_desks → seed_ext_demo → seed_rule_config → (python) scripts/seed_demo_books.py`。（`seed_rule_config.sql`/`menu_desk.sql` 无依赖、可任意时刻单独导；`seed_seats_desks.sql` 需 area(id=1) 先在、且 biz_desk/biz_seat.desk_id 列已建；均幂等）
  `role_perm.sql` 会**整段重建角色 10–12 授权**，必须先于 `menu_library_ext.sql`/`role_perm_ext.sql`，否则会冲掉新模块与只读授权。
- **时区**：本机 +0400，JDBC `serverTimezone=GMT+4`（`application-dev.yml`），座位占用查询用**字符串比较**避免 Date 时区偏移。
- **权限模型**：流通/采编除本职菜单外，另授了 读者/座位/研讨间/图书 的**只读**（`:list`），否则事务视图显示原始 ID。见 `sql/role_perm_ext.sql`。
- **信用不变式**：`credit_score = clamp(Σ credit_log.delta, 0, 100)`；`credit_log` 追加型，建档 +100 起。
- **并发**：约座用座位悲观行锁 + 时段重叠校验（`SeatMapper.selectForUpdate`）；研讨间同理（`RoomMapper.selectForUpdate`）。
- **SnailJob**：执行器 `libraryAutoJob`（`LibraryAutoJobExecutor`）串起 8 类自动处置；改扫描逻辑在 `LibraryAutoServiceImpl`。
- **模板回写**：通用去痕增强（顶栏铃铛隐藏 + `deruoyi.sql` 基线）已回写基座 `ruoyi_template`。项目特有业务代码不回写。
- **子 Agent 纪律**：只写代码、不跑 mvn/git；并行批次 ≤5；编译报错一次即停、列因交用户。
