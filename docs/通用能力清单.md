## 详情

### 1. 媒体上传组件（MediaUpload / VideoView）✅
- **是什么**：业务图/视频的统一上传与展示，采用 **URL 约定**（字段直接存可访问 URL，不走 ossId）。
- **在哪**：
  - 前端：`plus-ui/src/components/MediaUpload/index.vue`（表单侧，`v-model:images` 逗号 URL / `v-model:video` 单 URL）、`plus-ui/src/components/VideoView/index.vue`（只读播放）。
  - 后端：`ruoyi-system` 的 `SysMediaController`（`POST /resource/media/upload`，`@SaCheckLogin`，图 10MB/视频 100MB，返回 `{url,fileName,type}`）。
  - 演示灌数据脚本：`scripts/上传媒体到MinIO_图片视频.py`。
- **怎么用**：表单 `<MediaUpload v-model:images v-model:video>`；详情 `<ImagePreview :src="row.images">` / `<VideoView :src="row.video">`。
- **数据约定**：多图字段存逗号拼接 URL，单值字段存单 URL；前缀要与 `sys_oss_config` 对齐。
- **验证**：端到端通过（多图+视频上传→字段落 MinIO URL→详情展示→MinIO 字节一致）。
- **设计稿**：`docs/specs/2026-07-17-media-upload-components-design.md`。
- **来源**：5 个项目普遍存在。

### 2. ① C 端接入基座（ruoyi-app + uni-app 骨架）✅
- **是什么**：一套"独立于后台 `sys_user` 的 C 端账号 + 登录 + 请求/上传/字典/分页"接入层。任何带小程序/H5 的项目复制即用。
- **在哪（后端 `ruoyi-modules/ruoyi-app`，包 `org.dromara.app`）**：
  - `AppUser`（`app_user` 通用账号表，建表 SQL 在 `ruoyi-app/src/main/resources/sql/app_user.sql`）。
  - `AppLoginHelper`（同一 `StpUtil`，loginId 前缀 `app_user:{id}` 与 sys_user 隔离；`getUserId()` 供业务模块拿当前 C 端用户）。
  - `AppAuthController`（`/app/auth/*`：登录/注册/getInfo/改昵称/改头像/登出 + `wxLogin` 预留桩）。
  - `IAppUserService`、`AppUserVo`（脱敏）、`AppDemoController`（`/app/demo/page` 分页示例，**可删**）。
- **在哪（前端 `uni-app/`）**：`src/utils/request.ts`（clientid+Bearer+401 防抖+silent）、`src/utils/upload.ts`（复用 `/resource/media/upload`）、`src/utils/dict.ts`（本地字典 label/tag 色）、`src/store/auth.ts`、`src/api/auth.ts`、`src/composables/useList.ts`（分页触底/下拉刷新）、页面 `pages/{index,login,mine,demo/list}`。
- **怎么用**：新项目复制 `uni-app/`，改 `src/config.ts`（`BASE_URL`/`CLIENT_ID`）即可对接；业务模块 `@Autowired IAppUserService` 或 `AppLoginHelper.getUserId()` 拿当前 C 端用户。
- **数据/集成约定**：多租户下登录在放行路径无租户上下文 → 查/插 `app_user` 用 `TenantHelper.ignore`；`security.excludes` 只放行 `/app/auth/login`、`/app/auth/register`；每个请求（含上传）带同一 `clientid`。
- **验证**：端到端通过（注册/登录 `app_user:` 命名空间 token / getInfo 脱敏 / 分页 / 未登录 401 / 头像上传→MinIO 字节一致 / 中文 UTF-8 正确 / H5 构建 / Playwright UI 冒烟）。
- **设计稿**：`docs/specs/2026-07-17-app-access-base-design.md`。
- **来源**：有小程序的 4/4 项目各写一遍（宠物/二手用 app_user 独立表；本基座采纳）。

### 3. ② 站内消息/通知中心 🔧（feat/msg-center，进行中）
- **规划**：通用 `ruoyi-message` 模块——`app_notification`(通知/未读) + `app_message`(私信会话)，`NotificationHelper.send(...)` 供各业务触发点调用；C 端 `/app/notice/*`、`/app/message/*`；uni-app 通知/会话/聊天页（复用 `useList`）。
- **来源**：5/5 项目都有。合并后补详情与验证结果。
