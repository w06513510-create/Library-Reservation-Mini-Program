## 1. 对标产品/同类系统功能模块并集

### 1.1 座位/空间预约类(对标产品)

**超星学习通「座位预约」(高校主流,微信小程序/APP 双端)**
- 三种预约方式:A 预约选座(先选时间→区域→具体座位)、B 快速选座(设筛选条件由系统自动分配)、C 现场扫码选座(扫桌面二维码,当前时段直接落座/未来时段仍需签到)。
- 签到/暂离/退座:扫桌面二维码签到(前后 10 或 20 分钟弹性)、暂离(默认 20 分钟)、退座(手动/门禁联动)。
- 微信入口:关注公众号→读者服务→座位预约(仅首次登录)。
- 空间预约:研修间/研讨室属于"空间预约"模块,与单座预约并列。

**善思智慧图书馆座位预约系统(厂商方案)**
- 多终端接入:选座机、微信公众号、微信小程序、PC 网页、墨水屏桌签。
- 与门禁/闸机对接实现自动签到、暂离、签退。
- 可视化:区域座位以数字+热度图展示使用情况。
- 后台可对多场馆/多空间的座位进行编辑调整,前端实时更新。
- 与校园统一认证平台对接,读者用原账号登录,无需单独维护账号系统。

**黄冈师院座位预约系统采购需求(功能清单式规范)**
- 现场端预约首页:每楼层"总座位数+当前空位数"进入按钮。
- 楼层页:显示每层空位数,支持楼层间快捷切换;切换列表框大小/字体/位置可自定义。

**清华大学图书馆座位管理系统**
- 违规分三种类型(未签到/未签离/临时离开超时),按类型独立计次。
- 预约成功后 30 分钟内签到;开始 30 分钟后无法取消。
- 违约记录每学期初(3/1、9/1)清零。

**南开大学图书馆座位/研读间系统**
- 网页+微信双预约;选座机或扫码签到(起始后 30 分钟内)。
- 门禁刷卡自动签退;暂离/结束需在选座机刷卡或微信扫一扫。
- 研读间/研讨室与普通座位统一违约合并计数。

> **座位类功能并集(作为"全不全"基准):** 场馆/楼层/区域管理、座位管理(编号/类型/坐标/状态)、平面图可视化选座、快速选座、现场扫码选座、时段管理、预约、取消预约、签到(扫码/刷卡/门禁)、暂离与返回落座、续座(延长)、退座/签退、到期自动释放、超时未签到自动释放、暂离超时强制释放、占座监督(他人举报→限时落座否则释放)、违约计次、信用积分、黑名单/停用、履约记录、研讨间/研修间(空间)预约、个人预约记录查询、规则/公告发布、多终端(小程序/网页/选座机/墨水屏)。

### 1.2 图书借阅/流通类(对标产品)

**江苏汇文(Libsys)图书流通系统 — 高校占有率最高**
- 四大模块:**流通借还、流通管理、流通阅览、流通委托**;支持主馆/分馆/多校区。
- 流通借还:借书、还书、续借、预约、罚款;读者/借还快捷切换;WEB 流通;续借模式切换;智能流通(自动识别读者/图书条码);特权用户越权借阅/续借/预约;单册临时延期;借书地/还书地/罚款地权限控制(**通借通还**)。
- 硬件:一卡通接口、RFID、3M 自助借还。
- 流通委托:异地分馆委托借阅申请、图书划到、异地借阅;申请单/划到单/回库单打印。

**OPAC(联机公共目录检索系统,读者端入口)**
- 检索途径:题名、著者、主题词、索书号、ISSN、ISBN、系统号、条形码、全文;可设限(语言、起止年份、资料类型、馆藏位置)。
- 「我的图书馆」:借阅信息查询、借阅历史、自助续借、预约/取消预约、挂失、超期/委托到书/预约到书/荐购一站式展示。
- 增值:网上预约、异地委托借阅、订购征询、教参书推荐、催缺、预约到书、优先阅览、新书/专题推送。

**汇文应用服务系统(后台自动通知)**
- 到期/超期提醒、预约到书提醒、委托到书提醒、荐购处理结果通知(邮件/微信/短信)。

> **图书流通类功能并集(基准):** 采访荐购(读者荐购、师生选书)、验收登到、分类编目(套录/原编)、技术加工(贴条码/书标/磁条)、典藏分配、馆藏检索(OPAC 多途径)、借出、还入、续借、预约(hold)、预约到书通知、预约架取书、通借通还/异地委托、逾期处理、遗失/损坏赔偿(本项目改为记录+扣分,不涉款)、催还(含预约催还)、挂失/解挂、盘点、移库、剔旧注销、上下架、借阅历史与个人中心、消息提醒。

## 2. 座位预约完整生命周期与闭环

### 2.1 状态流转(正向主线)

```
[可预约] → 预约成功[待签到] → 签到[使用中] ⇄ 暂离[暂离中]
   → 退座/签退[已完成·履约+1]
```

### 2.2 每一步的介入人与反向/收尾出口

| 步骤 | 触发方 | 正向动作 | 反向/收尾出口 | 系统/定时任务动作 |
|---|---|---|---|---|
| 预约 | 读者(C端) | 选场馆→楼层→区域→座位→时段→提交 | **取消预约**(次日座位次日 7:00 前可无限次;当日座位限每日 1 次) | 校验并发数/黑名单/信用阈值 |
| 待签到 | 读者 | 到起始时间前后弹性窗(前后 10/20/30 分钟)扫码/刷卡/门禁签到 | **超时未签到** → 记违约、自动释放座位、当次预约取消 | **定时任务**:扫描超过弹性窗未签到的记录→释放+扣分 |
| 使用中 | 读者 | 落座学习 | **退座**(手动/门禁刷卡);到期系统自动结束 | **定时任务**:到达结束时间自动释放 |
| 暂离 | 读者 | 点"暂离"(默认 20 分钟保护期) | **暂离超时未返** → 强制退座、记违约 | **定时任务**:暂离计时超时→释放+扣分 |
| 续座 | 读者 | 结束前申请延长时段(如仍空闲) | 不续 → 到期自动释放 | 校验后续时段是否被占 |
| 被监督 | 其他读者 | 举报"占用但无人"(暂离状态不在监督范围) | 原用户 20 分钟内到场扫码落座 → 解除;否则 → 释放+原用户记违约;原用户"退座"离场 → 不算违约 | **定时任务**:监督计时超时→释放+扣分 |
| 签退完成 | 读者 | 退座/离馆门禁 | — | 记"履约成功 1 次" |
| 违约后 | 读者/管理员 | 违约累计触发扣分/黑名单 | **违约申诉**(非故意如闭馆忘签退,向工作人员说明) → 流通管理员**解除 1 次违约记录** | 阈值判定进/出黑名单 |

### 2.3 违约触发的四类情形(检索共识)
1. 预约后弹性窗内**未签到**(未及时取消)。
2. **暂离超时**未返回落座。
3. 收到**监督**提示后限时内未落座。
4. 使用完毕**未按时退座/签退**(含闭馆离馆未签退)。

## 3. 图书借阅完整生命周期与闭环

### 3.1 馆藏侧(采编管理员)状态流转

```
荐购/采访 → 验收登到 → 查重(ISBN/题名/著者/版本) → 分类编目(索书号) 
   → 技术加工(条码/书标/磁条) → 校对 → 典藏分配 → 上架[可借]
```
- 查重目的:避免同书异号/异号同书;复本按原书索书号,不同版本加附加区分号。
- 条码规范:成对粘贴(书名页下 1/3 + 封底右上角),连号,标明批次范围。
- 校对内容:索书号、价格、题名、著者、ISBN、条码号(一对)。

### 3.2 流通侧(读者+流通管理员)状态流转与出口

| 正向环节 | 触发方 | 反向/收尾出口 |
|---|---|---|
| OPAC 检索(题名/著者/索书号/ISBN/条码…) | 读者 | — |
| 借出[已借出] | 读者/流通台/自助机 | **归还[在馆]** |
| 续借(到期前;逾期或被预约则不可续) | 读者(OPAC/小程序自助) | 不续借 → 到期 |
| 逾期(**本项目仅记录+扣信用分,不罚款**) | 系统 | 归还后解除逾期状态 |
| 预约(hold,复本全借出时) | 读者 | **取消预约** |
| 预约排队(按时间先后自动排序) | 系统 | 前序读者不可续借该书 |
| 预约到书通知(Email/微信/短信) | 系统定时任务 | — |
| 预约架保留(3~7 天,各馆不同) | 系统 | **超保留期未取** → 记违约/顺延下一位/回归正常流通 |
| 取书借出 | 读者/流通台/自助取书柜 | — |
| 预约催还(在借图书被预约→催持书人提前还) | 系统 | 持书人归还 → 优先借预约者 |
| 遗失/损坏(本项目改为记录+扣分,不涉款) | 读者→流通管理员 | 补充/核销 |
| 剔旧/报损/核销/下架[注销] | 采编管理员(报批后) | — |

### 3.3 剔旧/注销/报损流程(采编+审批)
- 剔除标准:陈旧过时、复本过多、破损缺页且无保存价值。
- 流程:制定剔除计划 → (征求师生意见)→ 呈报审批 → 在财产登记系统与目录系统**注销登记**、更新馆藏。
- 损坏分级(深大例):可清除的勾画→记分;可修复→按书价 50% 修补费(最低 15 元/册);无法修复→按遗失标准;损毁磁条/条码/书标→加工费。
- 说明:**本项目定位"不涉及金额、不做支付"**,故上述赔款/罚款仅作背景参考,系统内落地为"记录+信用扣分+暂停借阅权限",归还/核销后恢复。

## 4. 信用分体系设计参考

### 4.1 真实系统采用的两种主流范式(检索所得)

**范式 A — 千分积分制(南开)**
- 初始 1000 分,每学期重置。
- 每次违约扣 100 分;累计违约 3 次即清零。
- 清零 → 暂停新增预约 3~15 天;暂停期满后积分恢复。

**范式 B — 分类违规计次制(清华/中传/贵医)**
- 不用分值,按违规类型独立计次。
- 清华:未签到/未签离/临时离开超时任一类满 3 次 → 黑名单禁选 3 天;解禁后该类计次清零。
- 中传:7 天内违规 ≥3 次 → 黑名单 7 天。
- 贵医:各类违规统一累计满 5 次 → 停用 7 天,停用期满计次归零;每学期初统一清零。

**恢复方式(检索结论):** 主流是"暂停期满自动恢复 + 每学期/寒暑假重置",**并无高校采用"每日自动回血 X 分"或"每次履约 +X 分"**;履约多为记录"守信次数",不加分。河北师大有"用积分在积分商城兑换'解除黑名单'道具"的特殊玩法。

### 4.2 可落地规则示例 **[知识补足,综合上述范式设计,建议本项目采用]**

> 采用"千分制 + 分类扣分 + 时间恢复 + 履约加分"混合方案,便于展示信用分体系亮点:

| 项 | 规则示例 |
|---|---|
| 初始信用分 | 100 分(封顶 100) |
| 座位·超时未签到(爽约) | -10 |
| 座位·暂离超时未返 | -5 |
| 座位·超时未签退 | -5 |
| 座位·被监督后未落座 | -10 |
| 图书·逾期还书 | 每册 -5(可按逾期天数递增,如每超 7 天再 -2) |
| 图书·预约到书超期未取 | -5 |
| 图书·遗失/损坏(记录不涉款) | -20,归还/核销后可申诉恢复 |
| 履约加分 | 按时签到并正常签退 +1/次;按时归还 +1/册(封顶 100) |
| 时间衰减恢复 | 无违约每满 30 天 +5(或每学期初重置为 100) |
| 阈值·预约限制 | <60 分:每日可约数减半;<40 分:仅可当日预约不可预约次日 |
| 阈值·黑名单 | <20 分 或 单类违约累计 3 次 → 进黑名单,暂停预约/借阅 7 天 |
| 黑名单解除 | 暂停期满自动解除并恢复至 60 分;或申诉通过后恢复 |

> 这套示例可直接支撑"信用分体系 + 定时任务自动违约判定/自动释放"亮点:定时任务负责扫描"超时未签到/暂离超时/监督超时/图书逾期"→ 自动释放/扣分/进黑名单;时间衰减恢复也由定时任务每日跑。

## 6. 各角色真实职责边界

### 6.1 真实图书馆部门分工(检索结论)
- **采编部(入口端):** 采访(制定采购计划、荐购/捐赠受理、验收登到)+ 编目(分类、著录、建机读书目、赋索书号)+ 典藏(藏地分配、加工)。是文献资源建设的基础。
- **流通部/借阅部/读者服务部(出口端):** 借还、预约、催还、通借通还、委托借阅、上架整架调架、报刊上下架、读者咨询导览、破损/赔书收集处理。直接面向读者。
- **协作分界(关键):** 涉及"采访/编目数据改变"(如需改书目、改索书号)的问题书 → 交采编部处理;仅"单册/物理"问题(书刊状态错误、书标缺失)→ 流通部自行处理。
- **系统/技术:** 通常由综合科或技术部负责系统配置、账号、统计。

| 取消预约 | 次日座位:次日 7:00 前不限次;当日座位:每日限 1 次 |

### 8.3 图书借阅约束(参考)
- 预约架保留期 3~7 天,超期未取回归流通并可记违约。
- 逾期未还:被预约的书不可续借;逾期册不可续借。
- 本项目**逾期仅记录+信用扣分,不收滞纳金、不做支付**;遗失/损坏改为记录+扣分+暂停权限,核销后恢复。

### 8.4 隐私
- 大屏与统计使用匿名化/聚合数据(如学习轨迹匿名化用于空间优化)。
- 读者个人借阅记录/违约记录仅本人及授权管理员可见。

## 关键提示给主 Agent(用于写 SRS 时避坑)
1. **本项目定位无金额**:所有真实系统里的"罚款/滞纳金/赔款"一律改写为"记录 + 信用扣分 + 暂停权限",归还/核销/申诉后恢复。术语表和逾期/遗失环节都已按此口径标注。
2. **信用分恢复机制**:检索显示真实高校基本不做"每日回血/履约加分",多为"暂停期满恢复 + 学期重置"。第 4.2 节的混合方案是**为凸显毕设亮点做的可落地设计**(知识补足),写 SRS 时可采用但需自洽。
3. **座位建模两层**:场馆→楼层→区域→座位(带坐标,支撑平面图);图书建模两层:书目(种)→馆藏(册,带条码)。这两点直接决定库表设计。
4. **定时任务清单**(亮点②落地):超时未签到释放、暂离超时释放、监督超时释放、到期自动释放、图书逾期判定扣分、预约架超期释放、信用分时间衰减恢复、黑名单到期解除。
5. **"约座/i自习/微书房"未直接命中**:检索显示高校主流实为**超星学习通座位预约、汇文流通/OPAC、善思/清华自研系统**;已用这些真实系统替代对标,功能并集更可信。
