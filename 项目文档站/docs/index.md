# 图书馆预约系统 · 毕设文档站

面向高校的**图书馆座位/自习室预约 + 图书借阅**一体化系统：读者用**微信小程序**自助约座、借还书、查信用分；管理端用 **RuoYi-Vue-Plus Web 后台**做流通、采编、系统配置与**数据可视化大屏**。两端共用同一个后端。

> 本项目定位 **无金额、不做支付**：真实图书馆里的"罚款 / 滞纳金 / 赔款"一律改为 **记录 + 信用扣分 + 暂停权限**，归还 / 核销 / 申诉后恢复。

## 三大亮点

1. **可视化平面图（选座 + 寻书，一图两用）**——同一套 楼层→区域→坐标 底图两用：**选座**（读者平面图点座预约、座位状态实时着色）+ **寻书**（按索书号把每册馆藏排架到书架坐标，读者在平面图上看到某本书在哪个区域/哪个书架，便于找书）。
2. **信用分体系 + 定时任务自动判定**——违约扣分 / 黑名单闭环；Spring `@Scheduled` 定时任务自动做"超时未签到释放、暂离超时释放、到期释放、图书逾期判定、信用分时间衰减恢复、黑名单到期解除"。
3. **数据可视化大屏**——座位占用热力、借阅排行、信用分布等实时指标一屏统览。
