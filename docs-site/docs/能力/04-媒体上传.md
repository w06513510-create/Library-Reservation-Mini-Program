# 媒体上传组件（MediaUpload / VideoView）

## 是什么

业务图 / 视频的统一上传与展示，采用 **URL 约定**：业务字段**直接存可访问 URL**，不走 ossId、不做 `@Translation` 解析。5 个参考项目普遍存在。

## 在哪

- 前端组件：`plus-ui/src/components/MediaUpload/index.vue`（表单侧）、`plus-ui/src/components/VideoView/index.vue`（只读播放）。
- 后端接口：`ruoyi-system` 的 `SysMediaController` —— `POST /resource/media/upload`（`@SaCheckLogin`，图 10MB / 视频 100MB，返回 `{url, fileName, type}`）。
- 演示灌数据脚本：`scripts/上传媒体到MinIO_图片视频.py`。

## 怎么用

表单侧（哪个 v-model 绑了就渲染哪个区，可纯图/纯视频/图视频合一）：

```vue
<MediaUpload v-model:images="form.images" v-model:video="form.video" />
```

详情侧（只读）：

```vue
<ImagePreview :src="row.images" />   <!-- images 是逗号拼接 URL -->
<VideoView :src="row.video" />       <!-- video 是单个 URL -->
```

C 端 uni-app 同样复用该接口：`utils/upload.ts` 的 `chooseAndUploadImages / chooseAndUploadVideo` → `/resource/media/upload`。

## 数据约定

- 多图字段（如 `images`）存**逗号拼接的多个 URL**；单值字段（`cover` / `video`）存**单个 URL**。
- URL 前缀要与后端 `sys_oss_config` 对齐，否则应用里点开图/视频 404。

!!! tip "与 ① 的关系"
    C 端接入基座的 `upload.ts` 直接复用本接口 `/resource/media/upload`（不另造 `AppOssController`）。两者拼成完整"C 端起步套件"。

## 验证（已通过）

多图 + 视频上传 → 字段落 MinIO URL → 详情 `ImagePreview` 显示、`VideoView` 播放 → MinIO 直取字节一致。
