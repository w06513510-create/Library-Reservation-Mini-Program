# ⑨ 通用互动（收藏 / 点赞 / 关注）ruoyi-interaction

## 是什么

用户对**任意业务对象**（`biz_type/biz_id`）的 **收藏 / 点赞 / 关注**，一张表覆盖三种动作，去业务耦合。5 项目里反复出现（宠物 帖子点赞/收藏/关注、社团设计 club_follow、二手 favorite_count 占位）。

## 在哪

后端 `RuoYi-Vue-Plus/ruoyi-modules/ruoyi-interaction`（包 `org.dromara.interaction`）：

- 表 `app_interaction`：`user_id × action(favorite/like/follow) × biz_type/biz_id`，唯一键 `uk_uabb` 防重。**取消互动为物理删除**（无审计价值，无 `del_flag`）。建表 SQL：`ruoyi-interaction/src/main/resources/sql/app_interaction.sql`。
- `IInteractionService`：动钱以外的"互动唯一入口"。
- C 端 `/app/interaction/*`，全部 `AppLoginHelper.getUserId()` 归属防越权。

前端 uni-app：`api/interaction.ts` + `composables/useInteraction.ts`（单对象详情页用）+ `pages/mine/favorites.vue`（我的收藏，`useList`）；`pages/demo/list.vue` 加 ❤ 演示。

## 服务方法

| 方法 | 用途 |
|---|---|
| `toggle(userId, action, bizType, bizId)` | 幂等开关：无则加返回 `true`，有则取消返回 `false` |
| `has(...)` / `count(action,bizType,bizId)` | 我是否操作过 / 该对象被多少人操作（赞数/收藏数/粉丝数） |
| `hasBatch(...)` / `countBatch(...)` | 列表渲染批量：这批我操作过哪些 + 各自计数 |
| `pageMyBizIds(userId, action, bizType, pageQuery)` | 我的收藏/点赞/关注 对象ID 分页 |
| `pageFollowing/pageFollowers(userId, pageQuery)` | 我关注的人 / 我的粉丝（返回 `AppUserVo`） |

## 怎么用

后端业务：

```java
// 收藏商品
interactionService.toggle(uid, InteractionAction.FAVORITE, "product", 1001L);
// 关注某人：biz_type=user, biz_id=目标 userId
interactionService.toggle(uid, InteractionAction.FOLLOW, InteractionAction.BIZ_TYPE_USER, targetUserId);
// 给自己的商品列表拼"我赞过没 + 赞数"
Set<Long> liked = interactionService.hasBatch(uid, InteractionAction.LIKE, "product", ids);
Map<Long,Long> likeCounts = interactionService.countBatch(InteractionAction.LIKE, "product", ids);
```

C 端：`POST /app/interaction/toggle {action,bizType,bizId}` → `{ active, count }`；`GET /app/interaction/my/page?action=favorite&bizType=product` 取我的收藏。

前端详情页（单对象）：

```ts
const { active, count, init, toggle } = useInteraction('like', 'post', postId);
onMounted(init);   // 拉初始状态
// 模板里 <text @click="toggle">{{ active ? '♥' : '♡' }} {{ count }}</text>
```

!!! tip "列表渲染别用 useInteraction"
    列表批量请让**后端在列表接口里**用 `IInteractionService.hasBatch/countBatch` 直接下发"我赞过没 + 赞数"，避免前端 N 次请求。`useInteraction` 只给单对象详情页用。

## 数据约定

!!! warning "计数不落业务表"
    计数从 `app_interaction` **实时聚合**（COUNT），通用模块**不改业务表、不加 `like_count` 冗余列**。高并发场景由业务侧自行缓存/冗余。

## 验证（已通过）

回归测试 `ruoyi-admin/src/test/java/org/dromara/test/InteractionVerifyTest`（`@SpringBootTest` 真实 DB，3 用例）：点赞 toggle 幂等（true/false）+ 计数、收藏 `hasBatch`/`countBatch`/我的列表、关注 → following/followers（返回 `AppUserVo`）。全 reactor `mvn compile` + uni-app `build:h5` 通过。

## 范围外（YAGNI）

业务表冗余计数列；互动触发通知（业务自行 `NotificationHelper.send`）；"谁赞了"带头像明细（favorite/like 返回 bizId；follow-user 才返回 `AppUserVo`）；点赞排行榜。
