# ③④ 支付与钱包（ruoyi-pay）

## 是什么

与业务无关的**钱包对平引擎** + **支付宝沙箱充值**，绑定 `app_user`。构建成本最高、正确性要求最严，一次做对处处可用。

## 在哪

后端 `RuoYi-Vue-Plus/ruoyi-modules/ruoyi-pay`（包 `org.dromara.pay`）：

- **`IWalletService`** —— 动钱唯一入口：`getOrCreate / recharge / deduct / freeze / unfreeze / checkInvariant`。
- 表 `app_wallet`（三层余额 `balance / frozen / total_recharge` + `@Version` 乐观锁）、`app_fund_flow`（append-only 流水）、`app_recharge`（充值单，`out_trade_no` 唯一）。建表 SQL：`ruoyi-pay/src/main/resources/sql/pay_wallet.sql`。
- 支付宝：复用 `ruoyi-common-alipay`（`@ConditionalOnProperty(alipay.app-id)`）。
- C 端 `/app/wallet/*`、`/app/recharge/*`；`/app/recharge/notify` 放行。

## 三条正确性保证

!!! danger "动钱的三道锁"
    - **CAS 防超扣**：出账走条件 UPDATE `... where balance >= #{amount}`，影响行数=0 即失败抛异常——原子、无读改写竞态。
    - **幂等**：`app_fund_flow.idempotent_no` 唯一键 + 动钱前查重；并发同键靠唯一键硬兜底，净效果只入账一次。
    - **对平不变式**：`checkInvariant = balance − (Σ入 − Σ出)`，正常**恒为 0**，可随时查库自检。

## 怎么用

业务扣款 / 冻结（自带业务幂等键）：

```java
walletService.deduct(userId, amount, "order", orderNo, idempotentNo, "支付扣款");
walletService.freeze(userId, amount, "order", orderNo, idempotentNo, "下单冻结");
BigDecimal diff = walletService.checkInvariant(userId); // 应为 0
```

充值：C 端 `/app/recharge/create` →（已配支付宝）返回支付表单 / （未配）走 `/app/recharge/simulatePaid` 模拟到账。

## 支付宝配置与降级

- 真钥放 `RuoYi-Vue-Plus/ruoyi-admin/src/main/resources/application-alipay.yml`（**已 gitignore、切勿提交**；模板见同目录 `.example`）。
- `@ConditionalOnProperty(alipay.app-id)`：**未配置不影响应用启动**；未配时 `simulatePaid` 直接结算入账，使"充值→对平"在无沙箱凭证下也能验证。

!!! warning "上线前必做"
    正式上线前务必配 `application-alipay.yml` 真钥（见 SOP 04 §G）。查单在事务内做网络调用（高并发下连接占用隐患）；对平只覆盖可用余额，`frozen` 为对手方（引擎须为其唯一写入者）。

## 验证（已通过）

- 端到端：充值 100+50 → 余额 `150.00`、流水 2 条（balance_after 100→150）、`checkInvariant=0.00`、未配 Alipay 走 simulate 降级。
- **回归测试** `ruoyi-admin/src/test/java/org/dromara/test/WalletEngineVerifyTest`（`@SpringBootTest` 连真实 DB，5 用例）：recharge/deduct/freeze/unfreeze 每步对平=0、CAS 超扣被拦、幂等生效；真实支付宝下单签名（复用沙箱配置，未配则 `assumeTrue` 跳过）。
- 运行方式：根 pom `skipTests=true` 默认跳过，`mvn test -pl ruoyi-admin -DskipTests=false -Dtest=WalletEngineVerifyTest` 显式运行。

## 范围外（YAGNI）

提现 / 分账 / 佣金账户 / 捐赠 / 多币种。
