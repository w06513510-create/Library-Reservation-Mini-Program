# ① C端接入基座（ruoyi-app + uni-app 骨架）

## 是什么

一套"独立于后台 `sys_user` 的 C 端账号 + 登录 + 请求/上传/字典/分页"接入层。任何带小程序 / H5 的项目，复制基座即用。有小程序的参考项目（4/4）此前都各写了一遍，抽成基座后不再重抄。

## 在哪

**后端** `RuoYi-Vue-Plus/ruoyi-modules/ruoyi-app`（包 `org.dromara.app`）：

- `AppUser` —— `app_user` 通用账号表（建表 SQL：`ruoyi-app/src/main/resources/sql/app_user.sql`）。
- `AppLoginHelper` —— 同一 `StpUtil`，loginId 前缀 `app_user:{id}` 与 `sys_user` 隔离；`getUserId()` 供业务模块拿当前 C 端用户，非 C 端 token 访问抛 403。
- `AppAuthController`（`/app/auth/*`）—— 登录 / 注册 / getInfo / 改昵称 / 改头像 / 登出 + `wxLogin` 预留桩。
- `IAppUserService`、`AppUserVo`（脱敏）、`AppDemoController`（`/app/demo/page` 分页示例，**可删**）。

**前端** `uni-app/`（Vue3 + TS 骨架）：

- `src/utils/request.ts` —— clientid + Bearer + 401 防抖重登 + silent。
- `src/utils/upload.ts` —— 复用后端 `/resource/media/upload`。
- `src/utils/dict.ts` —— 本地字典 label / tag 色。
- `src/store/auth.ts`、`src/api/auth.ts` —— 登录态 / 认证 API。
- `src/composables/useList.ts` —— 分页 composable（触底加载 + 下拉刷新）。
- 页面 `src/pages/{index,login,mine,demo/list}`。

## 怎么用

新项目复制 `uni-app/`，只改 `src/config.ts`：

```ts
export const BASE_URL = /* H5 走 /dev-api 代理；小程序直连 */ 'http://localhost:8199';
export const CLIENT_ID = 'app00000000000000000000000000001'; // 前后端约定固定串
export const TENANT_ID = '000000';
```

业务后端拿当前 C 端用户：

```java
Long uid = AppLoginHelper.getUserId();     // 未登录抛 401，非 C 端 token 抛 403
// 或注入 IAppUserService 按 id / 手机号查
```

C 端分页页面（composable 收敛模板）：

```ts
const { list, loading, finished, reload, loadMore, onRefresh } = useList({
  fetch: (params) => request({ url: '/app/demo/page', params }), pageSize: 10, immediate: false
});
onReachBottom(loadMore);
onPullDownRefresh(onRefresh);
```

## 数据约定 / 集成坑

!!! warning "四个必踩点"
    1. **租户上下文**：登录/注册在放行路径上、无租户上下文 → 查/插 `app_user` 用 `TenantHelper.ignore(...)`；`tenant_id` 由 DDL 默认 `'000000'` 兜底。
    2. **clientid 一致性**：每个请求（含 `uploadFile`）都带同一 `clientid` 头，否则拦截器抛 `-100`；上传最易漏带。
    3. **放行范围**：`application.yml` 的 `security.excludes` 只放行 `/app/auth/login`、`/app/auth/register`，**切勿放行整个 `/app/**`**。
    4. **token 字段**：登录返回 `{ token }`（非 `access_token`）。

## 验证（已通过）

注册 / 登录（token 内含 `app_user:` 命名空间）/ getInfo 脱敏 / 分页 / 未登录 401 / 头像上传→MinIO 字节一致 / 中文 UTF-8 正确 / uni-app `build:h5` / Playwright UI 冒烟（注册→登录→首页→分页→我的）。

## 范围外（YAGNI）

实名认证 / 信用分 / 钱包（见 ③④）/ 多角色 / 业务归属列 / 微信 openid 换取逻辑（只留列 + 端点桩）/ 登录端加密（文件保留、默认关）。
