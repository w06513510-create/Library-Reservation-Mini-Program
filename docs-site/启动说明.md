# 启动说明（维护者用）

本文件不进入文档站导航（位于 `docs/` 之外），仅供维护者本机启动/构建使用。

## 运行环境

复用本机已有的 `admindocs` conda 环境（mkdocs 1.6.1 + mkdocs-material）：

- Python（Git Bash 路径）：`/c/Users/lwf/.conda/envs/admindocs/python.exe`
- Windows 路径：`C:\Users\lwf\.conda\envs\admindocs\python.exe`

## 本地预览（热重载）

```bash
cd "D:/code_shop/Template/docs-site"
PYTHONUTF8=1 PYTHONIOENCODING=utf-8 /c/Users/lwf/.conda/envs/admindocs/python.exe -m mkdocs serve
# 浏览器打开 http://127.0.0.1:18100
```

> 端口 18100，避免与其他文档站（18088 / 18099）冲突。

## 构建静态站点（交付前自检）

```bash
cd "D:/code_shop/Template/docs-site"
PYTHONUTF8=1 PYTHONIOENCODING=utf-8 /c/Users/lwf/.conda/envs/admindocs/python.exe -m mkdocs build --strict
```

- `--strict`：坏链接、nav 缺页会导致构建失败。
- 构建产物输出到 `D:/code_shop/_site-ruoyi-template-docs/`（在仓库之外，不污染文档源、不进 git）。

## 目录约定

- `mkdocs.yml`：站点配置与导航（`docs_dir: docs`）。
- `docs/`：全部文档源。
  - `README.md`：首页索引。
  - `能力/`：各通用能力一页一篇（00-总览 + 5 篇）。
  - `glossary.md`：术语与约定。
- 权威源（本站只做说明，细节以下列为准）：`../docs/通用能力清单.md`（台账）、`../docs/specs/*`（设计稿）、`../docs/templates/*`（代码模板）、各模块 `../RuoYi-Vue-Plus/ruoyi-modules/ruoyi-*`。

> Windows 下别用 `conda run` 跑含中文输出的命令（GBK 转码会崩），直接调环境 python 并强制 `PYTHONUTF8=1 PYTHONIOENCODING=utf-8`。
